MediFlow — Hospital Appointment & Patient Portal

MediFlow is a modern, responsive hospital website designed to help patients explore hospitals, find doctors, and navigate appointment-related services through a simple and user-friendly interface.

Features

- Hospital Directory: Explore hospitals in Karachi with links to their websites or location information.
- Doctor Directory: Browse doctor information.
- Appointment Interface: Access the appointment booking interface.
- Patient Registration: User-friendly registration interface.
- Token Tracker: View the token tracking interface.
- My Account: Access the account section.
- Responsive Design: Designed to work across desktop, tablet, and mobile screens.
- Modern Navigation: Easily move between website sections.

Technologies Used

- HTML5
- CSS3
- JavaScript
